  empty, so H1 = 0 there carries no information. H1 rests on one reply.

  one reply both graders call an offer. The one DeepSeek false alarm above shows the
  graders are not noise-free in the other direction.
- **No offers appeared at mid-task turns in either arm**, so H2 and H3 show the rule adds
  no harm there, not that it prevents any.
- Effort actually served is not visible (`HARNESS-NOTES.md`); records state it as
  requested. Subagent effort is unknown.
- n = 10 a cell: a harm that happens once in 20 sessions can pass.
